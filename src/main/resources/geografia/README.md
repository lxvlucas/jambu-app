# Recorte municipal

Malha simplificada de São Luís, código IBGE 2111300, obtida em 22/10/2026 pela
[API de malhas do IBGE](https://servicodados.ibge.gov.br/api/v3/malhas/municipios/2111300?formato=application/vnd.geo+json&qualidade=minima).
Usada para validar pins próprios e recortar importações. A simplificação pode
exigir revisão de pontos próximos à divisa; não é validação de endereço postal.
Nenhuma localização do usuário é inferida ou armazenada por essa validação.
